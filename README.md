# Projetos SENAI — Desenvolvimento de Sistemas

Repositório índice para organizar e documentar projetos desenvolvidos durante o curso de **Desenvolvimento de Sistemas do SENAI**. Cada projeto permanece em seu próprio repositório, com sua estrutura e instruções de execução preservadas.

## Objetivo

Reunir em um só lugar os projetos do curso, identificar a disciplina relacionada e facilitar o acesso à descrição, às tecnologias e às instruções de cada trabalho.

## Projetos — Desenvolvimento de Sistemas

| Projeto | Descrição | Tecnologias |
| --- | --- | --- |
| [VivaBarra Turismo](https://github.com/brenofsb/Vivabarra) | Site informativo sobre turismo na Barra, em Salvador, desenvolvido para o curso do SENAI. | HTML, CSS, Python, Django e SQLite |
| [Controle de EPI](https://github.com/brenofsb/epi) | Sistema para cadastro e gerenciamento de equipamentos de proteção individual, colaboradores e empréstimos. | Python, Django e SQLite |

## Como consultar e executar um projeto

1. Escolha um projeto na lista acima.
2. Abra o repositório pelo link correspondente.
3. Consulte o README daquele projeto para conhecer seu objetivo, funcionalidades, tecnologias, arquivo principal, pré-requisitos e comandos de execução.
4. Siga as instruções do projeto escolhido; requisitos e comandos variam entre repositórios.

Este repositório funciona como um catálogo: os códigos e arquivos de cada projeto continuam nos respectivos repositórios, sem cópias ou alterações em suas estruturas.
